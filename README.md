## Overview
This project transforms a traditional portfolio into an interactive "Retro Desktop" environment. It features a custom windowing system where users can drag, minimize, and explore different sections of the site as if they were using a classic OS.

## Features
- **Interactive Window Management**: Drag, focus, and toggle windows for a true desktop experience.
- **Retro Aesthetic**: A nostalgic UI inspired by classic operating systems, built with modern CSS and DaisyUI.
- **Responsive Animations**: Fluid motion and physics powered by Framer Motion.
- **PWA Ready**: Optimized for mobile and desktop use with a specialized desktop-only view when accessed on larger screens.

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [DaisyUI](https://daisyui.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```
